Tomcat-RS Compatibility Runtime — it works!

An incremental Rust rewrite of Apache Tomcat.

v1.0.0 — first stable release.

If you can read this page, the Rust HTTP/1.1 connector accepted your connection, the mapper routed the request to the default ROOT web application, and the static resource handler served this file — all on the Rust side.

Servlet, JSP, and WebSocket application code runs on an embedded JVM reached through the JNI bridge (build with --features jvm). Try the operator endpoints: /health, /manager/text/list (loopback-only by default). See the project repository for architecture, roadmap, and release notes.
